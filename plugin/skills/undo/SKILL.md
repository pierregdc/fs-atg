# /undo

Appelle immédiatement `fs_undo` (`action="undo"` ou `action="list"` si l’utilisateur veut voir la liste des sauvegardes) avec le workspace courant. Indique le fichier restauré/supprimé et le nombre de sauvegardes restantes.
