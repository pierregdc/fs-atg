# /compact

Appelle `fs_session` avec `action="compact"` et le workspace courant pour compacter la session **France Student** sans écrire de fichier (indique le pourcentage de contexte uniquement s’il est retourné ; pour compacter le fil Antigravity lui-même afin de réduire les tokens des prochains tours MCP, recommande la commande `/compact` native d’Antigravity).
