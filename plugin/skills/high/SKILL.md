# /high

Appelle immédiatement `fs_delegate` avec `/high ` + la demande exacte (privilégier blocs ciblés, logique complexe, audit ou plan compact pour économiser les tokens Antigravity), `contextMode="minimal"`, `waitSeconds=45` et le workspace courant. Applique `response` si besoin (`planB: true` + `parts` si échec). N’appelle `fs_job_status` que si le job n’est pas encore terminé.
